Harbour Lights — an original spot-the-difference game: two near-identical hand-drawn pictures side by side, 8 hidden differences per scene, three scenes (a sunset harbour market, a garden tea party, a lantern night festival). Click a difference on either picture to ring it in gold, watch the counter and the clock, spend hints wisely, and clear all 24 differences. Playable with mouse and keyboard, offline, in any desktop browser.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — no build step, no network.
